# 作品集网站

采用已选定的 C 温暖手绘风格完成的单页静态作品集。使用已确认的“林悦”示例资料；人物及公司为虚构，邮箱仅用于展示。

## 打开网站

在线浏览：[作品集网站](https://wangxian2018.github.io/portfolio/)。

主页为本项目根目录的 `index.html`。直接双击即可在普通浏览器中浏览，无需安装依赖或联网下载字体。

如需通过本机地址预览，在本项目目录打开 PowerShell，执行：

```powershell
python -m http.server 4174 --bind 127.0.0.1
```

然后在浏览器打开 `http://127.0.0.1:4174`。按 Ctrl+C 停止预览服务。这个地址仅供当前电脑访问。

## 内容维护

- 个人资料、卡片和详情文字：`index.html`。
- 页面样式与手机适配：`styles.css`。
- 弹窗与图片失败占位：`script.js`。
- 头像与五个作品的图片：`images/`。现有 PNG 为无损优化版本；第 5 个作品暂用灰色占位图 `photo-tool-placeholder.svg`。所有图片均为本地文件，每张小于 300KB；原始素材未改动。
- 每个作品卡片的 `data-project` 对应文档末尾同名 `template`，维护时应同时修改卡片摘要与详情模板。
- 三个首屏样稿：`样稿/style-a.html`、`style-b.html`、`style-c.html`。样稿统一引用 `../images/avatar.png`，相互切换仍可用。

## 使用说明

点击任意作品卡片可以查看完整说明；点击“关闭”、按 Esc 或点击遮罩空白处可关闭。使用 Tab 和 Enter 也能操作作品卡片。

联系按钮会请求打开设备的邮件应用，不会通过网站发送邮件。邮箱为 `linyue.demo@example.com`，不保证能够收信；也可以手动选中并复制邮箱。

项目没有账户、数据库、跟踪统计、远程字体或第三方资源。标题采用系统楷体及系统回退字体，正文采用设备自带无衬线字体；不同设备的字体笔形可能略有不同。刷新后详情弹窗关闭，页面内容保持不变。

## 发布

公开仓库：[wangxian2018/portfolio](https://github.com/wangxian2018/portfolio)。GitHub Pages 使用 `main` 分支的根目录 `/`，入口为 `index.html`；根目录的 `.nojekyll` 用于直接发布静态文件。

发布文件仅包括网站源码、压缩图片、三个首屏样稿及本说明和配置。需求单、验证记录、预览截图、旧版文件及本机临时产物保留在本地，通过 `.gitignore` 排除。
